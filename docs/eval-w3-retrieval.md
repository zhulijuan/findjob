> 测试集：`data/eval/retrieval_testset.jsonl`（25 条：fact 8 / 口径 6 / 改述 5 / 多跳 3 / 语料外 3，gold 块级标注，人工审核）

> 评测明细：`logs/eval/eval_<时间戳>.jsonl`（每次运行快照）｜变更记录：`logs/eval/last_state.json` 自动对比

## 指标口径说明

| 指标 | 含义 | 风控类比 |
|---|---|---|
| recall@1 | 正确答案块（gold）恰好排在第 1 位的题目占比，最严格的"一次命中"指标 | Top1 捕获率 |
| recall@3 / @5 / @10 | gold 出现在前 3 / 5 / 10 名的题目占比，放宽排名门槛只看"找没找到" | 前 N 名捕获率（类似 lift 表逐层捕获） |
| MRR@10 | 每题第一个 gold 的排名取倒数再平均：第 1 名记 1.0、第 2 名记 0.5、第 3 名记 0.33，前 10 名都没中记 0——同时衡量"找没找到"和"排得靠不靠前" | 命中质量加权得分 |
| 语料外题 | 无 gold，不计入上述指标；用于定性检查"资料里没有的内容会不会瞎答"，明细见 jsonl | 反编造校验 |

判读方法：recall@10 高但 recall@1 低 = "找得到但排不对"，是 reranker 的目标场景；recall@10 也低 = "根本没找到"，要改语料、分块或查询改写。

## 关键发现

1. **语义联想（BGE-M3）的真实水平**：真·零重叠行话改述（"首逾"→FPD30）联想成功 rank=1；半重叠改述（"兜底机制"→人工复核、"90天处置"→M3 委外催收）能召回但排名偏后（rank 2~5）；大跨度改述（"负面清单"→禁止用途）top10 全失。
2. **多跳题 vector 100% vs bm25 33%**：跨文档问题与 gold 块字面重叠少，语义检索完胜稀疏检索。
3. **reranker 价值显性化**：改述题 recall@1 从 20% 提到 60%，总体 recall@1 +9.1pp、MRR +0.046——cross-encoder 精排对"召回了但排不对"的场景收益最大。
4. **查询改写实测**（改写功能首次启用）：题22"放款的负面清单"经 LLM 扩写为"贷款发放负面清单/放款禁入清单/不予放款情形/风控准入负面清单"后，gold 块从 top10 外提升至 rank=2——大跨度改述的解法是改写而非更强的 embedding。
5. **互补性结论**：BM25 在部分改述题上靠残存词面锚点反超 vector（题25"放款批次"命中"放款月份分组"），印证"混合检索不是为了平均分，是为了消除单路的失效模式"。

## 变更追踪实验（2026-11-24，机制首跑）

一次完整的"改 → 评 → 决策 → 回退 → 确认"循环，展示变更追踪机制的实际价值：

| 轮次 | 变更 | bm25 recall@1 | bm25 MRR@10 | 结论 |
|---|---|---|---|---|
| 基线（210238） | — | 72.7% | 0.826 | — |
| 实验（221430） | 词典新增 3 词：个人信用贷款、消费金融公司、风险监测预警模型 | **68.2%（-4.5pp）** | **0.795（-0.030）** | 无一题改善，题6/题15 排序劣化 |
| 回退复测（230738） | 移除上述 3 词 | **72.7%（恢复）** | **0.826（恢复）** | 确认负向影响全部由新词引起 |

**经验**：BM25 分词变化会改变全局词频统计（IDF/文档长度分布），即使新词不直接出现在查询里也可能拖累排序；词典调整必须过评测闸门，不能凭直觉。hybrid/hybrid+rerank 两轮均不受影响，体现向量路对稀疏路扰动的缓冲作用。

> 机制说明：每次 `--eval` 自动对比知识库快照（语料 hash / 词典词条 / 索引 hash / 配置）生成变更清单，`--note` 人工备注，报告内嵌"与上次对比"差值表——让每次知识库迭代的效果可量化、可归因、可回滚。

## 变更追踪机制

每次 `--eval` 自动执行：

1. **知识库快照**：语料文件逐个 hash、BM25 词典词条清单、FAISS/BM25 索引文件 hash、关键配置（mode/分块/top_k/RRF/rerank/rewrite 开关）
2. **与上次对比**：自动生成"本次变更"清单（语料增删改、词典新增/移除词、索引重建、配置变更），配合 `--note` 人工备注写入报告
3. **指标差值表**：与上次评测逐指标对比，只列出变化的行（recall 用 pp、MRR 用绝对值），直观看"改了什么 → 涨了多少"
4. **产物**：`logs/eval/eval_<ts>.jsonl`（逐题明细）+ `.meta.json`（变更+汇总）+ `.md`（报告）+ `last_state.json`（下次对比基线）
